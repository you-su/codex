# Windows 桌面大肥鱼

完整解压 [便携版 ZIP](https://github.com/you-su/codex/releases/latest/download/fish-api-pro-windows-x64.zip)，双击 **start-pet.bat**。适用 Windows 10/11 64 位，内置 Python 和 Qt，无需安装。

- 透明悬浮窗口，始终置顶，关闭网页后仍显示。
- 按住左键拖动，松开记住位置；单击互动，双击打开聊天。
- 右键菜单：打开模型终端、安静模式、收起气泡、退出桌宠。
- 聊天会自动连接或启动本地服务，使用终端配置的模型和故障切换；需要先填写 API 密钥，调用可能计费。
- 气泡显示回答摘要，完整回答在桌宠聊天窗口；支持多轮与新对话。
- 聊天窗口关闭后桌宠仍运行；右键退出桌宠后终端服务保留，可用“关闭程序.bat”停止服务。
- API 密钥重启服务后重新填写。桌宠会话保存在 settings.json，位置在 pet-position.json。
- 本版尚不含语音输入、朗读或声音克隆。
- 便携版增加 Qt 图形组件，压缩包会比旧版大。不要仅复制 desktop_pet.py 到旧版运行。

# 大肥鱼 API 模型终端 Pro 1.0

## Windows 解压即用版
下载 [fish-api-pro-windows-x64.zip](https://github.com/you-su/codex/releases/latest/download/fish-api-pro-windows-x64.zip)，适用 Windows 10/11 64 位。
完整解压，打开 Fish-API-Pro 文件夹，双击 start.bat。包内 runtime/ 自带 Python，无需另外安装，也无需管理员权限。启动会打开浏览器；没有打开时访问 http://127.0.0.1:8765。
请保留启动窗口，使用结束后关闭程序。不要在压缩包内部直接运行。

## 源码版启动
GitHub Code → Download ZIP 和 Releases 中的 Source code 仅包含源码，不含 Python。源码运行需要安装 Python 3.10+，然后双击 start.bat 或运行 `python server.py`。
停止：Ctrl+C 或双击“关闭程序.bat”。

## 新增功能
- 多轮对话：本地保存最多 100 个会话，每个会话最多 50 轮；支持系统提示词、最近 20 轮上下文和故障切换。
- 会话 Markdown 导出、会话删除；失败请求不会写入聊天记录。
- 配置 JSON 导出与追加导入（最多 100 个端口/次），兼容原版 settings.json 的端口字段。导入先校验全部端口，密钥不导入、不导出。
- 从服务商读取模型列表，复制模型 ID 后在端口编辑中使用。
- 数据与工具页：累计 token、保存会话数、增强会话请求成功/失败次数与最近响应耗时。
- 修复附件缺少 logo 导致的一键启动检查失败，使用内置 SVG 图标。
- 保留原版端口管理、优先级、故障切换、余额、批量检测、音频素材和运行日志。

## 使用流程
模型端口 → 新增 API → 填写基础地址、密钥、模型 → 检测 → 多轮对话 → 新建会话。
密钥只驻留内存，重启后重新填写。会话正文和系统提示词明文保存在 settings.json；运行日志不记录正文。
统计中的增强会话请求数与耗时只覆盖新版多轮对话；token 同时包含原有调用统计。
导出的端口配置不包含聊天记录或音频。完整备份需复制 settings.json、voices/ 和 logs/。

## 边界与验证
QQ、桌宠控制、语音克隆与 TTS 仍未接入；音频功能保存的是参考素材。
上游使用 OpenAI 兼容协议（含 DeepSeek），非流式返回。故障切换会向备用提供商发送上下文，超时后重试可能产生重复费用。
本机单用户服务，请求依次处理，上游超时 20 秒。没有提供公开网络部署或多人账号功能。
17 项后端测试覆盖原有功能、配置导入校验、多轮上下文、故障切换和失败消息不落盘。
云环境禁止创建监听 socket，未完成 HTTP 启动与浏览器视觉验证。未使用真实付费 API 联调；模型实际可用性取决于服务商、网络和账户权限。
运行测试：`python -m unittest discover`。

# 大肥鱼 API 模型终端

本地可运行 MVP，Python 3.10+，无需安装第三方依赖。Windows 双击 start.bat，或执行 `python server.py`，浏览器访问 http://127.0.0.1:8765。关闭终端停止服务。

## 已实现
- 四个页面：终端首页、模型端口、模型配置、关于我们。
- API 新增、编辑、单个删除、预选、全选与批量删除确认。
- DeepSeek / OpenAI 兼容协议；模型列表连通性检测与真实测试对话。
- DeepSeek 账户余额；累计本工具调用返回的 total_tokens。
- 联动偏好保存；配置存入 settings.json，密钥仅保存在内存，重启需要重新填写。

## 使用
添加端口，填写名称、基础地址、协议、密钥和服务商模型 ID。DeepSeek 推荐基础地址 https://api.deepseek.com；OpenAI 兼容服务使用其要求的基础路径，通常含 /v1。点击检测查询状态，点击测试对话进行实际调用（可能计费）。

接口可达仅表示 /models 成功，不能保证生成服务可用。检测失败可能来自网络、鉴权或服务商不支持模型列表；可使用测试对话进一步确认。DeepSeek 余额按账户展示，同一账户多个端口的余额不可相加。其他服务商余额接口尚未实现。Token 不是账户历史总用量，删除端口也会移除对应本地统计。

## 后续 DSH / harness 与 QQ 接入边界
当前是独立本地程序，不是可以安装的 DSH 插件，不宣称兼容未知 SDK。server.py 的 remote 为提供商调用入口，action 为本地业务入口，index.html 为界面。迁移时按目标 SDK 注册页面、存储与生命周期，再将对应请求委托至业务层。

需要目标 harness / DSH 的官方插件清单格式、SDK 版本、安装示例，以及 QQ 大肥鱼消息收发协议和桌宠语音事件协议。确定这些信息后再实现适配器；不要将本地 X-Local-Token 当作第三方插件认证协议。

模型配置中的开关目前只保存偏好，没有真实 QQ 收发、TTS、语音转发或桌宠控制。关于我们按需求保留“暂时未开发”。

## 安全与限制
仅监听 127.0.0.1；写请求需要每次启动生成的会话令牌，校验 Host；不支持跨域调用。远程 API 仅允许 HTTPS，本机模型可 HTTP；禁止自动重定向以免密钥随跳转发送。密钥不返回前端、不写入配置；本机用户仍应妥善保护运行环境。服务使用单线程，检测期间其他请求会等待，单个上游请求超时为 20 秒。配置为单用户本机用途。

余额协议参考：https://api-docs.deepseek.com/api/get-user-balance/

## v0.2.0 当前端口与自动切换
终端首页可选择当前使用端口、设置备用优先级（数字越小越优先）以及开关自动切换。点击“使用当前端口对话”，首先调用当前端口；余额不足、HTTP 错误、超时、无效响应时按优先级依次尝试备用端口，缺少密钥或模型的端口跳过。每次请求每个端口最多尝试一次，成功端口成为后续当前端口。全部失败显示错误及记录，不无限循环。恢复后的旧端口可手动切回。删除当前端口后选择优先级最高的剩余端口。

此功能作用于 /api/send；/api/chat 是指定单端口诊断，不执行自动切换。后续 QQ 适配器应使用统一路由入口 routed_chat。切换会使用各端口配置的模型并将同一消息发往备用服务商；超时后重试可能产生重复费用。无后台轮询，实际请求才触发故障切换，历史检测结果不作为永久禁用依据。优先级、当前端口和最近调用记录持久保存；密钥仍仅驻留内存。

验证：8 项模拟上游单元测试覆盖手动切换、余额错误故障转移、全部失败、关闭切换、缺密钥跳过、删除当前端口、优先级校验及异常响应。运行 `python -m unittest test_routing.py`。尚未使用真实付费 API 密钥联调。

## v0.4.0 本地音色参考素材
模型配置页面底部提供 QQ 大肥鱼和桌宠两个独立音频上传入口，可上传、替换、试听。支持浏览器可解码音频（如 MP3/WAV/M4A/OGG，具体依浏览器），原文件不超过 100MB、时长不超过 15 分钟。浏览器本地解码转换为 16kHz 单声道 16-bit PCM WAV，后端再次检查真实 WAV 时长及完整性。文件只保存到项目 voices/，配置保存在 settings.json，重新启动不会丢失；替换成功后清理旧素材。请备份 settings.json 和 voices/，升级不要覆盖个人配置。

此功能保存音色参考素材，不包含声音训练、音色克隆、TTS 合成、QQ 发送或桌宠播放的服务接入。上传不代表已生成定制声音。后续需要确定可支持参考音频的语音引擎和 QQ/桌宠协议，各语音供应商可能要求短于 15 分钟的样本。长音频解码需要额外内存，浏览器不支持的编码请先转为 MP3 或 WAV。

验证：13 项后端测试通过（包括准确 15 分钟允许、超时长拒绝、非法/空/截断文件、目标校验、替换和独立保存），JavaScript 语法和四页渲染检查通过。未完成真实浏览器上传与音频播放验证。

## 运行日志与语音保存按钮

## 关闭程序
双击“关闭程序.bat”关闭本地大肥鱼服务。新版通过本机会话认证后正常退出并写入日志；处理中的 API 请求会先完成。旧版不支持关闭接口时，脚本核对网页身份、127.0.0.1:8765 的监听进程及 Python server.py 命令，再停止该进程。无法确认身份或权限不足时不停止其他进程，请手动关闭旧终端窗口。浏览器页面不会自动关闭，旧 start.bat 的 pause 窗口可能仍需按任意键退出。
