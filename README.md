# 大肥鱼 API 模型终端

## Windows 解压即用

[下载 Windows 10/11 64 位便携版](https://github.com/you-su/codex/releases/latest/download/fish-api-pro-windows-x64.zip)

完整解压 → 打开 `Fish-API-Pro` → 双击 `start.bat`。

自带 Python，不需要另外安装。首次发布须等待 [Windows 构建](https://github.com/you-su/codex/actions) 通过后下载链接才会生效。

**请下载 Releases 里的 `fish-api-pro-windows-x64.zip`。Code → Download ZIP 以及 Source code ZIP 是源码，需要另装 Python。**
